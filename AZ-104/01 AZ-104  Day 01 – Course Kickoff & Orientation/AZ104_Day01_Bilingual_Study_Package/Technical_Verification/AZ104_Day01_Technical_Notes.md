# AZ-104 Day 01 — Technical Verification and Corrections

> Source transcript is preserved without alteration. These notes distinguish current technical definitions from statements or possible speech-to-text errors in the lecture. Not every point has been independently researched for this package; verify exam requirements against official Microsoft Learn documentation before exams.

| Lecture wording or theme | Clarification for accurate study |
|---|---|
| “AZ-400” appears when introducing the course | Context is **AZ-104**. AZ-400 is a different, DevOps-engineering exam. |
| AZ-900 / AZ-104 / AZ-305 mapped directly to L1/L2/L3/L4 job levels | Certifications don't universally confer support tier levels; employers define responsibilities. |
| AVD expanded as “Azure Virtualization Desktop” | Correct product name is **Azure Virtual Desktop**. |
| “GVD” for Google cloud desktop services | That is not a standard universal counterpart to AVD; check the actual service name. |
| AWS EC2, S3 and Route 53 used amid Azure examples | These are **AWS** services; Azure counterparts include Azure Virtual Machines, Azure Storage and Azure DNS (not feature-identical). |
| Resource group treated as all servers/VMs as a collective noun | In Azure, a **resource group is a management container** for Azure resources; it is not simply the plural form of resource. |
| “PSU = Platform Service Unit” | On servers, PSU commonly means **Power Supply Unit**. |
| Data centers may operate at temperatures below 0°C as a norm | Do **not** use this as an operational recommendation. Follow equipment specifications, applicable standards and provider guidance. |
| A new server purchase after establishment described as OPEX | Equipment acquisition may still be **CAPEX**; classify costs by actual accounting rules. |
| “P1 must respond within 5–10 minutes” | Such deadlines are **organization- and contract-specific**, not universal. |
| High CPU automatically equated with urgent P1 | Prioritize actual business impact and urgency; CPU alone is an indicator, not a universal severity classifier. |
| Cloud computing always OPEX; on-prem always CAPEX | Real arrangements can mix capital and operating expenses; evaluate actual contracts and accounting treatment. |
| The lecture ends before the P1 restoration example finishes | Do not infer any remaining resolution targets from the missing recording. |
