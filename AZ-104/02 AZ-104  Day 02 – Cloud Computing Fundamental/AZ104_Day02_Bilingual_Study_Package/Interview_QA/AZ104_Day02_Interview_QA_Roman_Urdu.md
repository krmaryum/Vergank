# AZ-104 Day 02 — Interview Questions & Answers (Roman_Urdu)

> These are supplementary interview-preparation answers based on lecture topics; they are not a verbatim classroom exchange.

## Q1. What is on-premises infrastructure?

**Answer:** Company ke apne ya contracted premises mein company-managed servers, networking, storage aur facilities.

## Q2. What does DHCP provide?

**Answer:** DHCP client ko dynamically IP configuration aur aam tor par gateway/DNS options deta hai.

## Q3. What is DNS?

**Answer:** DNS naam ko IP address jaise records se resolve karta hai.

## Q4. Why use AD DS?

**Answer:** AD DS enterprise users, authentication aur policies ko centrally manage karta hai.

## Q5. Explain CAPEX versus OPEX.

**Answer:** CAPEX bari initial asset investment; OPEX recurring operations cost.

## Q6. What is disaster recovery?

**Answer:** Major disruption ke baad critical services restore karne ka plan, aksar alternative site par.

## Q7. Define RTO.

**Answer:** RTO: disruption ke baad service restore karne ka target maximum time.

## Q8. Define RPO.

**Answer:** RPO: waqt ke hisaab se maximum acceptable data-loss window.

## Q9. Why use virtualization?

**Answer:** Shared hosts par alag VMs chala kar utilization aur provisioning flexible hoti hai.

## Q10. What differs between Type 1 and Type 2 hypervisors?

**Answer:** Type 1 hardware par directly; Type 2 host operating system ke upar chalta hai.

## Q11. Can every VM gain RAM or vCPU with zero downtime?

**Answer:** Nahi. Hot-add hypervisor, VM settings, guest OS aur workload par depend karta hai.

## Q12. What is public cloud?

**Answer:** Provider operated cloud services jo aam tor par multiple tenants ke liye hoti hain.

## Q13. What is private cloud?

**Answer:** Ek organization ke liye dedicated cloud, chahe on-prem ho ya hosted.

## Q14. What is hybrid cloud?

**Answer:** Private/on-prem aur public cloud environments ko integrate karna.

## Q15. What is multi-cloud?

**Answer:** Do ya zyada cloud providers ki services use karna.

## Q16. What is pay-as-you-go?

**Answer:** Resource consumption ke mutabiq billing, har service ke pricing rules ke saath.

## Q17. What is vertical scaling?

**Answer:** Ek instance ki CPU/RAM jaisi capacity barhana.

## Q18. What is horizontal scaling?

**Answer:** Load share karne ke liye aur instances add karna.

## Q19. What is high availability?

**Answer:** Redundancy aur resilience se service downtime kam karna.

## Q20. What does IaaS provide?

**Answer:** Cloud infrastructure; customer guest OS, apps aur data manage karta hai.

## Q21. What does PaaS provide?

**Answer:** Managed platform/runtime; developer app aur data par focus karta hai.

## Q22. What does SaaS provide?

**Answer:** Provider ki hosted ready-to-use application.

## Q23. Does stopping an Azure VM always stop all charges?

**Answer:** Nahi. Disks, reservations, IP/network ya doosre resources ka charge reh sakta hai.

## Q24. How do you choose an Azure region?

**Answer:** Latency, data residency, services, resilience, cost aur compliance ko dekhein.

## Q25. What is a cloud shared responsibility model?

**Answer:** Service type ke hisaab se provider aur customer ki security/operations responsibilities alag hoti hain.

## Q26. How would you protect the diamond-business site?

**Answer:** MFA, least privilege, backup, monitoring, secure network aur tested DR plan use karenge.

## Q27. How can cloud costs be controlled in a lab?

**Answer:** Budgets, alerts, auto-shutdown, tags aur unused resources delete karke; residual charges check karein.

## Q28. What does cloud not eliminate?

**Answer:** Architecture, governance, security, monitoring aur DR ki zaroorat cloud se khatam nahi hoti.

## Q29. What is the airline analogy in the lecture?

**Answer:** Poora plane khareedne ke bajaye ticket lena shared cloud infrastructure consume karne ka example hai.
