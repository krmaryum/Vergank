# AZ-104 Day 02 — Roman Urdu Summary Report

## Class overview
Is class mein samjhaya gaya ke organizations **traditional on-prem** se **virtualization** aur phir **cloud consumption** ki taraf kyun aayi. Diamond-business ka real-world scenario aur Azure account preparation main references hain.

## Learning objectives
1. Servers, DHCP, DNS, AD DS aur application services ki zaroorat samajhna.
2. Data center ki cooling, redundant power, networking aur extra capacity plan karna.
3. CAPEX aur OPEX ka difference classroom costing se samajhna.
4. DR, replication, RTO aur RPO ko alag-alag explain karna.
5. Virtualization, consolidation aur Type 1/Type 2 hypervisors samajhna.
6. Public/private/hybrid/multi-cloud ka comparison.
7. Pay-as-you-go, scalability, reliability aur security risks samajhna.
8. IaaS/PaaS/SaaS mein responsibilities compare karna.
9. Azure free account aur region selection ki bunyadi planning.

## Practical classroom scenarios
- Nadeem aur Khalid diamond business ke owners aur instructor administrator.
- Data center, redundant facilities, extra servers aur networking ki demand.
- Sample **₹1 crore CAPEX** aur **₹20 lakh monthly OPEX**.
- Delhi primary site aur Bengaluru DR site.
- 16 GB RAM/4-core server ko expand karne ka example.
- Plane khareedne ke bajaye airline ticket lene ka cloud analogy.
- Azure trial aur regions ka instructor-guided tour.

## Key takeaways
- Cloud mein physical infrastructure hota hai, bas ownership aur operations alag hote hain.
- Identity, security, backup, DR aur cost planning cloud mein bhi zaroori hain.
- RTO recovery ka time aur RPO acceptable data-loss window hai.
- Deployment types aur IaaS/PaaS/SaaS alag concepts hain.
- Free tiers aur billing ke current rules ko check karna chahiye.
