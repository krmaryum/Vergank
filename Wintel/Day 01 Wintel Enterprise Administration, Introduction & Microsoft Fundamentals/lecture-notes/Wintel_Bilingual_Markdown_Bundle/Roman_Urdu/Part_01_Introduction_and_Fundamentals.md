## 6. Server Kya Hota Hai?

**Speaker 1:** **Server aisa system hai jo doosre computers ya users ko koi service provide karta hai.** Iske liye zaroori nahin ke aapke paas dedicated server hardware ho ya server operating system hi install ho. Aapka laptop ya desktop bhi server ki tarah kaam kar sakta hai.

### Example 1: Cybercafé mein Print Server

Misaal ke taur par maan lein ke main ek chhote cybercafé mein kaam karta hoon. Mere desktop ke saath ek printer connected hai aur paanch doosre computers usi network mein lage hue hain. Main chahta hoon ke woh paanchon computers us printer ke through print nikaal sakein.

Is situation mein mera desktop **Print Server** ki tarah kaam karega. Baqi systems network ke zariye shared printer ko access karenge. Dekha aapne? Ek aam desktop bhi service de kar server ka role perform kar sakta hai.

### Example 2: Applications Share Karne ke Liye FTP Server

Ab maan lein mujhe bohat se computers par Google Chrome, Mozilla Firefox, Adobe Reader, WinRAR, WinZip ya doosri applications install karni hain. Agar har system par alag alag internet se download karunga to waqt bhi lagega aur agar internet band ho to mushkil bhi hogi.

Is se bachne ke liye main installers ek dafa download kar ke apne computer mein rakh sakta hoon aur computer ko **FTP Server** bana sakta hoon. Network ke doosre computers uske IP address ke zariye connect kar ke files hasil kar sakenge.

**FTP ka full form File Transfer Protocol hai.** Jab aap website se software download karte hain to woh website kisi internet-connected server par hosted hoti hai. Kabhi kabhi `ping` ya `nslookup` commands ki madad se kisi hostname se related IP address maloom kiya ja sakta hai.

Instructor ne class mein ek command chalai aur example ke taur par IP address `151.101.105.91` hasil hua. Yeh us website ke saath associated address tha jise woh check kar rahe thay.

**Translator ka technical note:** Live class mein instructor ne aam website downloads ko FTP se jora aur SFTP ko upload se relate kiya. Technical taur par yeh distinction durust nahin: HTTPS bhi downloads ke liye use hota hai, aur FTP aur SFTP dono upload aur download support kar sakte hain. Yeh note sirf confusion se bachne ke liye hai; class ke example ka matlab barqarar rakha gaya hai.
