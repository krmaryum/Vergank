# Wintel Lab

**Zabaan (Language):** [English](README.md) | Roman Urdu

Mere **Wintel (Windows on Intel) class lab** ke liye beginner-friendly, step-by-step study bundles: Windows 10 host par **VMware Workstation Pro** mein Windows Server aur Windows ko virtual machines ke tor par install karna.

Har bundle ke hisse ek jaise hain, **English aur Roman Urdu** dono mein:

- **README**: poori install guide, har step ka screenshot, aur har step ke saath aasaan "Kyun?".
- **TROUBLESHOOTING**: asli masle aur un ke hal (Alaamat, Wajah, Hal, Sabaq).
- **INTERVIEW-QA**: 25 beginner interview sawal aur jawab.
- **quiz.html**: 25 sawalon ka practice quiz. Download karke kisi bhi browser mein kholein; internet ke baghair bhi chalta hai.

## Lab environment

- Host: Windows 10 Pro, Intel i5-4430 (4 cores), 16 GB RAM
- Hypervisor: VMware Workstation Pro 25H2
- VMs `D:\VMs` par rakhi hain
